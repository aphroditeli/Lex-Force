# Lex Force · 法治天下

> 口袋里的法律工具箱 —— 法典查阅、AI 案情分析、即时取证、起诉文书生成，数据全部留在你的手机上。

基于 HarmonyOS（ArkTS / API 24）原生开发的个人法律信息参考应用。核心设计原则：**数据本地化、端侧处理、隐私最小化** —— 无后端服务器、无第三方 SDK，账号、订阅、取证、案例等全部数据仅存储于设备本地。

## 功能一览

### 📚 法典库（离线优先）
- 内置六部常用法律全文：民法典（1260 条）、刑法、劳动法、行政诉讼法、消费者权益保护法、治安管理处罚法（2025 修订版）
- 分卷下载到本地，离线查阅与全文搜索
- 未下载时可预览部分章节
- 条号智能搜索：输入「296条」自动匹配「第二百九十六条」
- 情景搜索：口语描述直达法条（如「半夜吵」→ 治安管理处罚法第 88 条 / 民法典第 294 条）

### 🤖 AI 法律助手
- 9 类纠纷场景（噪声、劳动、消费、人身伤害、租赁、交通、家事、诈骗、漏水等）
- 案情描述自动结构化提取：时间、地点、证人、证物线索，结果可编辑
- 口语叙述 → 文书化表达改写
- 匹配相关法条与处理指引（本地规则引擎，无需联网）

### 📷 即时取证
- 调起系统相机拍照/录像（免独立相机权限）
- 照片经像素级水印烧录拍摄时间 + 地点（逆地理编码，失败退回经纬度）
- 视频原样保存 + 自动截取首帧生成水印封面照
- 取证记录本地持久化；照片视频仅存本机图库，不外发

### 📝 起诉文书生成
- 表单填写（原告/被告/法院/诉求/补充说明）+ 案情要素自动填充
- 一键导出 PDF（PDF Kit）并支持系统打印

### 🎙 语音输入
- CoreSpeechKit 端侧语音识别，语音不上传云端
- 说案情代替打字，自动进入 AI 分析流程

### 👤 账号与订阅
- 本地注册/登录（密码加盐 SHA-256 摘要存储）
- 四档订阅：月度 ¥238 / 季度 ¥558 / 年度 ¥998 / 终身 ¥4980
- 订阅记录防篡改签名 + 系统时间回拨检测
- 到期前 7 天提醒，不支持自动续费
- 繁简中文切换

## 技术要点

| 主题 | 实现 |
|------|------|
| 语言/框架 | ArkTS + ArkUI（声明式 UI） |
| 目标平台 | HarmonyOS NEXT（API 24） |
| 本地存储 | Preferences（账号/订阅/下载记录/取证记录）+ 沙箱文件（法典全文 JSON） |
| 端侧识别 | CoreSpeechKit + AudioCapturer（PCM 流喂入） |
| 图像水印 | OffscreenCanvas 像素级烧录（避免屏幕 Canvas 像素错位） |
| 安全控件的相机/图库 | cameraPicker / SaveButton，免常规敏感权限 |
| PDF/打印 | PDF Kit 生成 + @ohos.print |
| 订阅防破解 | SHA-256 记录签名 + 时间回拨冻结（注：绝对防破解需服务端校验） |

## 项目结构

```
entry/src/main/ets/
├── entryability/          # Ability 入口
├── pages/
│   ├── Index.ets          # 5 Tab 主框架（首页/法典/助手/咨询/我的）
│   ├── CodeDetail.ets     # 法典全文查阅/搜索
│   ├── AssistantResult.ets# AI 分析结果（可编辑要素）
│   ├── EvidencePage.ets   # 即时取证
│   ├── LoginPage.ets      # 登录/注册（注册前须同意三份法律文件）
│   ├── LegalDocPage.ets   # 法律文件全文阅读
│   ├── SubscribePage.ets  # 订阅套餐
│   └── ...
└── model/
    ├── LawRepository.ets  # 法典下载/加载/搜索
    ├── LegalEngine.ets    # 本地规则分析引擎
    ├── EvidenceStore.ets  # 取证记录持久化
    ├── Subscription.ets   # 订阅状态与防篡改校验
    ├── Account.ets        # 本地账号
    ├── LegalDocs.ets      # 隐私政策/免责声明/订阅协议全文
    └── ...
```

法条全文数据（`resources/rawfile/law/*.json`）由 `law_src/parse_law_md.py` 从公开法律文本库生成。

## 构建与运行

1. 使用 DevEco Studio 打开工程（需 HarmonyOS NEXT SDK，API 24+）
2. 配置签名（或使用 Debug 签名）
3. `Build → Build Hap(s)` 后运行到真机/模拟器

> 应用内支付当前为演示流程；正式收费以华为应用市场 IAP 为准。

## 法律声明

本应用提供的所有内容均为**一般性法律信息参考**，不构成法律意见或律师服务。重要法律决定请务必咨询执业律师。详见应用内（注册时须阅读同意）：

- 《隐私政策》
- 《免责声明》
- 《订阅服务协议》

内置法律法规文本来源于公开发布的文本库整理，请以全国人大及其常委会公布的官方正式文本为准。
